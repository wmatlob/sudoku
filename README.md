## Sudoku solver
V2.0.0
Using the interface to implement the Sudoku


The app takes a .CSV file ending with " " to read find the first solution if there is a solution.
Otherwise, the app will notify that there is no solution for the .CSV game file.

## Folder Structure

The workspace contains two folders by default, where:

- `src`: the folder to maintain sources
- `lib`: the folder to maintain dependencies
